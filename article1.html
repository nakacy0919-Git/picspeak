なぜ英語で言葉が出にくいのか？—— 写真描写という練習法

KN

中島 浩平 (Kohei Nakashima)

Founder of Global Classroom / English Educator

Language

「文法問題は解けるのに、英語で話そうとすると言葉がすぐに出てこない。」 授業をしていると、こうした悩みを持つ生徒に何度も出会います。 これは単純に「英語力がない」という話ではありません。 語彙や文法を知っていることと、限られた時間の中でそれらを組み合わせて発話することは、別の負荷を伴うからです。

私が授業でPicture Description（写真描写）を使うようになったのは、 「何を話すか」をゼロから考えなくても、目の前の情報を使ってすぐ発話を始められるからです。 写真の中には、人、物、場所、動作、色、位置関係など、話すための手がかりが最初からあります。

この記事で伝えたいこと：
Picture Descriptionは「英語脳を作る魔法の方法」ではありません。 しかし、視覚的な手がかりを使いながら、限られた時間で英語を組み立てて声に出す練習として、 授業に取り入れやすいタスクの一つだと考えています。

1. 「知っている」と「その場で使える」の間には距離がある

学習者は、単語の意味や文法規則を知っていても、会話の中ですぐに使えるとは限りません。 話すときには、伝えたい内容を決め、使う語を選び、文の形を組み立て、発音しながら、 次に何を言うかも考える必要があります。

第二言語習得研究では、学習者が実際に言語をoutput（産出）することによって、 「言いたいのに言えない部分」や「自分に不足している表現」に気づく可能性が議論されてきました。 ただし、outputを増やせば自動的に習得が起きるという意味ではありません。 繰り返し、フィードバック、適切な難易度などの条件も重要です。

2. 写真があると「話題を作る負担」を減らしやすい

フリートークでは、「何について話そう」「どこから始めよう」という内容面の負担があります。 Picture Descriptionでは、写真そのものが共通の話題になります。 たとえば、最初は次のような短い情報だけでも構いません。

  • A boy is running.
  • There are two bicycles.
  • The woman is standing near the door.
  • It looks like a busy street.

そこから、場所、動作、位置、数、服装、推測へと少しずつ情報を増やせます。 私の授業では、この「目に見えるものから始められる」ことが、 発話の最初の一歩を作りやすくしていると感じています。

3. Picture Descriptionは研究でも使われるスピーキングタスク

写真描写や絵のストーリー描写は、第二言語研究で特別珍しい課題ではありません。 L2のoral productionを調べる研究では、複雑さ（complexity）、正確さ（accuracy）、 流暢さ（fluency）などを観察するためのタスクとして使われています。

Cambridgeの研究でも、picture description taskは学習者の発話パフォーマンスを調べるために利用されており、 写真の中で起きていることを一定時間で説明させることで、 学習者がその場でどのように言語を組み立てるかを見ることができます。

だからといって、写真描写だけで会話力全体を測れるわけではありません。 相手とのやり取り、質問への応答、意見交換、交渉などは別の能力を含みます。 Picture Descriptionは、スピーキングの一部分を集中的に練習するタスクとして位置づけるのが適切です。

4. 「日本語を使わないこと」自体を目的にしない

元の記事では、「日本語を介さず英語を直接考える」「英語脳を作る」という表現を使っていました。 現在は、この言い方は少し単純化しすぎていると考えています。

学習者が頭の中で母語を使うこと自体は自然なことであり、母語は語彙理解や内容理解の足場にもなります。 大切なのは「日本語を使ったら失敗」ではなく、 毎回長い日本語文を完成させてから翻訳しなければ話せない状態から、少しずつ離れていくことです。

写真を見て “A man is…” “There is…” “Maybe…” と短い英語から始めることで、 完璧な日本語文を先に作らなくても発話できる経験を増やす。 私はPicture Descriptionを、そのための練習の一つとして使っています。

5. PicSpeakで大切にしているのは「トライ＆リトライ」

PicSpeakを開発した背景には、Global Classroomなどの国際交流で、 生徒が相手を前にしたときに「知っている英語をまず使ってみる」経験をもっと増やしたいという思いがあります。

PicSpeakでは写真を提示し、音声認識を利用して認識された語やWPMなどを表示します。 これらは英語力を完全に測定するスコアではなく、自分の発話を振り返り、もう一度試すための目安として設計しています。

一度目は単語だけ、二度目は文で、三度目は場所や理由まで加える。 そのように同じ写真で表現を少しずつ増やしていけば、 「話せた・話せなかった」の二択ではなく、自分の発話の変化を見ることができます。

授業で使うなら、こんな流れから始められます

  • 30秒：写真を見て、知っている単語をできるだけ挙げる。
  • 30〜60秒：短い文で写真全体を説明する。
  • 再挑戦：言えなかった表現を確認し、同じ写真でもう一度話す。
  • 発展：「なぜ？」「この後どうなる？」など、推測や意見を加える。

Picture Descriptionの良さは、初心者なら単語や短文から、 上級者なら詳細描写・推測・ストーリー化まで、同じ一枚の写真で課題を調整しやすいことです。 私はこの柔軟さを、授業で大きな利点だと感じています。

“I know the grammar, but when I try to speak, the words do not come quickly.” I have heard this frustration from many students. Knowing vocabulary and grammar is not the same as being able to select and combine them under the time pressure of speaking.

I began using Picture Description because a picture gives learners immediate content to talk about. People, objects, actions, colours, locations, and relationships are already visible, so learners do not have to invent a topic before they begin speaking.

The main point of this article:
Picture Description is not a magical technique that creates an “English brain.” It is, however, a practical speaking task in which learners can use visual cues to build and produce language under limited time.

1. There Is a Gap Between Knowing Language and Using It in Real Time

Speaking requires learners to decide what they want to communicate, retrieve vocabulary, organize grammar, pronounce the message, and plan what comes next. A learner may therefore “know” a form without being able to use it immediately in conversation.

Research on second-language output has examined how producing language can sometimes help learners notice gaps in what they can say. This does not mean that more output automatically produces acquisition. Repetition, feedback, appropriate task difficulty, and opportunities to revise also matter.

2. Pictures Reduce the Need to Invent a Topic

Free conversation includes an additional challenge: deciding what to talk about. In Picture Description, the image provides a shared topic. Beginners can start with short statements such as:

  • A boy is running.
  • There are two bicycles.
  • The woman is standing near the door.
  • It looks like a busy street.

Learners can then add location, movement, number, clothing, relationships, or inference. In my classroom experience, this visible support often makes the first step into speaking easier.

3. Picture Description Is Also Used in L2 Speaking Research

Picture-description and picture-story tasks are commonly used in second-language research. Researchers use them to examine aspects of oral production such as complexity, accuracy, and fluency.

Studies published by Cambridge, for example, have used picture-description tasks to examine how learners produce language under task conditions. Such tasks make it possible to observe how learners organize language while describing the same visual stimulus.

A picture-description task does not measure every aspect of speaking. Interaction, responding to questions, negotiating meaning, and expressing opinions involve additional skills. I therefore view Picture Description as one focused type of speaking practice, not a complete substitute for conversation.

4. The Goal Is Not to Ban the First Language

The original version of this article used expressions such as “thinking directly in English” and developing an “English brain.” I now think those expressions oversimplify what learners actually do.

Using the first language mentally is natural and can support vocabulary and comprehension. The aim is not to tell learners that using Japanese is wrong. Instead, I want them gradually to become less dependent on constructing a complete Japanese sentence before translating it into English.

A picture allows learners to begin with short forms such as “A man is…,” “There is…,” or “Maybe…” and build the message from what they can already say.

5. PicSpeak Is Designed Around Try and Retry

My experience with Global Classroom and other international exchanges made me want to create more opportunities for students to use the English they already know before meeting an overseas partner.

PicSpeak uses speech recognition to show recognized words and measures such as WPM. These are not complete measures of English proficiency. They are intended as reference points that help learners review a performance and try again.

A first attempt might contain only words. A second attempt can use full sentences. A third can add location, reasons, or inference. Repeating the same visual task makes it easier for learners to notice how their own output changes.

A Simple Classroom Routine

  • 30 seconds: list as many visible words as possible.
  • 30–60 seconds: describe the overall scene in short sentences.
  • Try again: check missing expressions and repeat the same task.
  • Extend: add inference, reasons, or predictions about what may happen next.

One advantage of Picture Description is its flexibility. Beginners can work with words and simple sentences, while more advanced learners can add detailed description, inference, and storytelling.
